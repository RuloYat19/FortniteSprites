## Para cambiar de temporada default

Cambiar el `filtros` y el `limpiarFiltros`

## Orden de prioridad para calcular el Polvo al Extraer

1. Material específico (ej: Oro) + rareza + nivel

2. Variantes + rareza + nivel (si el material NO es Normal)

3. Todos Los Materiales + rareza + nivel (fallback general)
